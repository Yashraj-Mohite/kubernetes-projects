# Kubernetes Projects Portfolio

A collection of hands-on Kubernetes projects built to demonstrate 
cloud-native skills for DevOps/Cloud engineering roles.

## Projects

### Project 1 - Local K8s Cluster with Minikube
Set up a local Kubernetes cluster, deployed Pods and Deployments, 
exposed apps via NodePort Service.

### Project A - Rolling Updates & Rollbacks
Performed zero-downtime rolling updates and rollbacks on a live deployment.

### Project B - ConfigMaps & Secrets
Managed app configuration and sensitive data using ConfigMaps and Secrets.

### Project C - Resource Limits & Health Checks (Coming Soon)
Setting CPU/memory limits and liveness/readiness probes on pods.

## Tools Used
Kubernetes, Minikube, kubectl, Docker, Azure (AKS), YAML, Ubuntu/WSL2
